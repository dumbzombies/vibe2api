2 minutes
Use a Vibe-scoped key. A normal Mistral API key works for requests but will not draw on the $300 Vibe allowance — it bills the $30 pay-as-you-go account instead, and the quota shown here will stay at zero. Only the Vibe key reports a vibe_budget, which is what this proxy reads.
  1. 1
    Open the Vibe console

    Go to console.mistral.ai and sign in. This is the Vibe / Codestral-CLI page, not the main API keys page.

  2. 2
    Create a key on that page

    Keys created under API Keys are scoped to the pay-as-you-go account. The key must be issued from the Vibe section so it carries the subscription allowance.

  3. 3
    Check it is the right one

    Paste it below. This page will call GET /v1/billing/budget with it before saving — a Vibe key answers with vibe_budget; a normal key does not, and you will be told so rather than silently getting a key that never touches the allowance.
